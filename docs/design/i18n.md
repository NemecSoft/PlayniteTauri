# 国际化（多语言）

## 支持语言

| 语言代码 | 语言 | 状态 |
| --- | --- | --- |
| `en-US` | English（英语） | ✅ |
| `zh-CN` | 简体中文 | ✅ |
| `zh-TW` | 繁體中文 | ✅ |

## 实现方案（i18next + react-i18next，与 tauri-template 对齐）

### 结构

```
locales/                  # JSON 字典（i18next 资源）
├─ en-US.json             # 英语
├─ zh-CN.json             # 简体中文
└─ zh-TW.json             # 繁体中文

src/i18n/
├─ config.ts              # i18next 初始化（resources、fallbackLng、languageChanged 更新 <html lang>）
└─ index.tsx              # useI18n() 门面（底层调用 react-i18next useTranslation）
```

### 核心 API

```ts
// 方式一（推荐，react-i18next 原生）
const { t } = useTranslation();
t("toolbar_addGames")                  // 纯翻译
t("import_imported", { count: 5 })     // 插值 → "已导入 5 个游戏"

// 方式二（兼容门面，等价）
const { t, lang, setLang } = useI18n();
t("toolbar_addGames")
```

`t(key, vars?)` 支持 `{var}` 插值，由 i18next 处理（默认 `escapeValue: false`，React 已转义）。

### 语言切换与持久化

- 语言值存于 `settings.language`（后端持久化），三语为 `en-US` / `zh-CN` / `zh-TW`。
- `App.tsx` 监听 `settings.language` → `setLang()` → `i18n.changeLanguage()` → 全部文本即时刷新。
- `i18n.on("languageChanged")` 同步更新 `document.documentElement.lang`。
- 语言选择控件在 设置 → 通用 → 语言。

### 覆盖范围

标题栏、侧边栏、工具栏、导入向导、空状态、三种视图、右键菜单、编辑弹窗、设置界面
（通用/外观/主题/游戏库/插件）等所有 UI 硬编码文本均通过 `t()` 翻译。

> 注：系统托盘菜单文本由 Rust 后端生成，暂未纳入前端 i18n（属 OS 层组件）。
