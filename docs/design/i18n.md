# 国际化（多语言）

## 支持语言

| 语言代码 | 语言 | 状态 |
| --- | --- | --- |
| `en-US` | English（英语） | ✅ |
| `zh-CN` | 简体中文 | ✅ |
| `zh-TW` | 繁體中文 | ✅ |

## 实现方案（自研轻量 i18n，`src/i18n/`）

### 结构

```
src/i18n/
├─ index.tsx              # React Context + useI18n() hook + t() 翻译函数
└─ locales/
   ├─ en.ts               # 英语字典（键集合的"源"）
   ├─ zh-CN.ts            # 简体中文
   └─ zh-TW.ts            # 繁体中文
```

### 核心 API

```ts
const { t, lang, setLang } = useI18n();

t("toolbar_addGames")                    // 纯翻译
t("import_imported", { count: 5 })       // 带占位符插值 → "已导入 5 个游戏"
```

`t(key, vars?)` 支持 `{var}` 占位符插值，`vars` 为 `Record<string, string|number>`。

### 类型安全

- 以 `en.ts`（`as const`）的键作为唯一 `TranslationKey` 来源。
- `Dict = Record<TranslationKey, string>` 保证三个字典**键完全一致**（缺键编译报错）。
- `t(key)` 中 `key` 必须是合法键，类型错误在编译期暴露。

### 切换与持久化

- 语言值存于 `settings.language`（后端持久化）。
- `App.tsx` 监听 `settings.language`，变化时 `setLang()` 同步到 Context → 全部文本即时刷新。
- 语言选择控件在 设置 → 通用 → 语言。

### 覆盖范围

标题栏、侧边栏、工具栏、导入向导、空状态、三种视图、右键菜单、编辑弹窗、设置界面
（通用/外观/主题/游戏库/插件）等所有 UI 硬编码文本均通过 `t()` 翻译。

> 注：系统托盘菜单文本由 Rust 后端生成，暂未纳入前端 i18n（属 OS 层组件）。
