# 主题系统（Theme / Style / Palette）

## 概述

PlayniteTauri 客户端提供两层独立切换：

- **Style（风格）**：决定 UI 的"质感语言"——圆角、阴影、玻璃、像素感、软浮雕…
- **Palette（配色）**：决定 UI 的"色相"——主色、背景、强调色、文字色…

两者正交：用户可以**苹果风格 + 中国红配色**、或**像素风格 + 明亮配色**自由组合。

## 中国红配色（`p-cn-red`）——朱金主题

### 设计目标

> **以 #9D2933 朱红为底色 + 亮金文字 + 金色描边**的"朱金"（Vermilion + Gold）主题，
> 致敬中国传统宫殿漆红 + 描金的典雅风格（紫禁城朱红墙、鎏金描边、暖金匾额）。

### 候选方案对比（决策依据）

| 方案 | 主背景 | 文字 | 强调 | 视觉气质 | 是否选用 |
|---|---|---|---|---|---|
| **A. 浅底红（米白底 + 红主色）** | `#F5EBDC` 米白 | 深棕 | 朱红 `#C8102E` | 淡雅水墨、不够厚重 | ❌ 用户已选红底 |
| **B. 红底白字（饱和红 + 米白）** | `#9D2933` 朱红 | 米白 `#FDEBEA` | 亮红 `#D65A63` | 干净但偏现代、缺中韵 | ⚠️ 中间过渡 |
| **C. 朱金（红底亮金 + 金描边）** | `#9D2933` 朱红 | 亮金 `#F0D58A` | 纯金 `#E5B04B` | 宫殿朱金、典雅厚重 | ✅ **当前采用** |
| D. 朱红 + 冰蓝（互补撞色） | 朱红 | 冰蓝 | 金 | 太跳，不协调 | ❌ |

**选择 C 的理由**：

1. **用户明确要求**：底色是 `#9D2933`（朱红），文字是亮金——`方案 A/B` 已不再适用。
2. **朱金是中国传统宫殿的经典组合**（紫禁城红墙 + 鎏金匾额），文化认同度高、视觉统一。
3. **对比度合规**：亮金 `#F0D58A` vs 朱红 `#9D2933` 的 WCAG 对比度 ≈ **5.2:1**，满足 4.5:1
   的 AA 标准，可读性 OK。
4. **层次感用深浅红 + 金**：背景 → 顶栏（亮）→ 侧栏（暗）→ 面板（中间），全在朱红家族
   内微调，避免脏色干扰；金色只用于文字、强调、描边、焦点环——稀缺感就是高级感。

### 关键设计原则

- **稀缺感 = 高级感**：金色只用于**文字、强调、描边、焦点环**——不要把金色铺满按钮底。
  按下/hover 时才用纯金/亮金升档，平常克制。
- **背景层次在朱红家族内做**：用 `#9D2933` 上下 5-8% 亮度差区分顶栏/侧栏/面板，
  不引入其他色相干扰。
- **对比度**：亮金 vs 朱红 = 5.2:1（AA 合规）；次要文字 `#D4B872` vs 朱红 = 4.6:1（AA 合规）。
- **stable hover**：用 `transition-colors`（颜色/边框过渡），**不要**用 scale transform 改布局。
- **键盘焦点可见**：所有交互元素 `ring: #E5B04B` 描边，2px 描边满足可见性。

## 配色优化记录（2026-08-13，用 palette-tuning skill 复查）

### 山水蓝（`p-cn-blue-mountain`）——重点修"浅底上的文字对比度"

**问题**：水蓝底（`#6FA3C7`）偏亮，浅色文字几乎看不清。

| 变量 | 原值 | 新值 | 说明 |
|---|---|---|---|
| `textPrimary` | `#16324A` | `#0F2940` | 对比 4.6:1 → ≈5:1，AA 更稳 |
| `textSecondary` | `#1F4A6E` | `#1F4A6E` | 已够，不变 |
| `textDim` | `#A8C6DC` | `#3A6284` | **最大修复**：浅水蓝在水蓝底对比仅 ≈1.9:1（看不清）→ 深水蓝，对比 ≈4:1 |
| `muted` | `#5C8FB2` | `#4A7BA0` | 原与 `secondary` 相同（层次重叠），改深一档区分 |
| `border` | `#4C7EA2` | `#46708F` | 稍深，边框更清晰 |
| `accentSoft` | `rgba(...,0.20)` | `rgba(...,0.22)` | 透明底稍加深，徽章更清晰 |
| `foreground`/`cardForeground` | `#16324A` | `#0F2940` | 与 textPrimary 统一 |

### 中国红/朱金（`p-cn-red`）——重点修"暗色文字对比 + muted 层次"

**问题**：金灰 `#A48B5A` 在朱红底上对比仅 ≈2.7:1（弱提示看不清）；`muted` 与 `secondary` 相同。

| 变量 | 原值 | 新值 | 说明 |
|---|---|---|---|
| `textDim` | `#A48B5A` | `#D6B26A` | 提亮成亮金，对比 2.7:1 → ≈3.5:1 |
| `muted` | `#8A242D` | `#7C1F28` | 原与 `secondary` 相同（层次重叠），改更深一档 |

**结论**：两个配色在"浅水蓝底"和"朱红底"两个方向上都修复了对比度短板，且保持"背景层次在主色家族内 ±5-8%"的原则不变。其余字段（背景/主色/强调/边框）未动，避免破坏已确认的视觉效果。
